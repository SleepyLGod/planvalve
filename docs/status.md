# 状态查看

先运行网关，再在另一个终端运行 `npm run status`。英文版为 `npm run status -- --lang en`，一次性打印也接受 `--lang en`；默认中文。监控与模型客户端相互独立，q / Ctrl-C 只关闭监控。

| 操作        | 效果                           |
| ----------- | ------------------------------ |
| ↑ / ↓       | 选择请求；详情中逐行滚动       |
| Enter / Esc | 打开详情／返回列表             |
| PgUp / PgDn | 详情滚动十行，列表移动十条     |
| ← / →       | 上一页／下一页，每页 50 条     |
| Tab         | 本次运行／全部历史，回到第一页 |
| q / Ctrl-C  | 恢复终端并退出监控             |

窗口缩小时列表采用紧凑行；详情按窗口宽度折行，默认详情以中文分区显示用量、请求信息和参数处理；按 R 才显示完整原始 usage、metadata 和英文 API 字段。表头与数据共用显示列宽，中文字符按终端宽度计算，数值右对齐，超长字段以省略号标记。支持 `NO_COLOR=1`。控制字符会转义，防止请求参数改变终端显示。

概览始终统计当前运行：执行数／并发上限、等待数／容量、暂停状态、启动间隔、请求及 token 预算。切换全部历史只改变列表范围，不改变上方预算和用量含义。

输入、输出、总计为已经确认的核心用量；尚在执行的请求可能还没有 usage。cached 属于输入子集，reasoning 属于输出子集，均不额外计入总量。细分显示已知累计值和未知次数，核心未知也单独统计。默认服务是固定模拟样本，不代表真实账号消耗。独立真实测试会标明“官方订阅 · 真实测试”或“ChatGPT plan · LIVE test”，其用量来自本次真实响应。

状态页的时间是快照时间；连接失败时保留原有快照并标记 连接中断，而不是把数值清零。不会因断连而发起模型调用。

打印命令：

```bash
npm run status -- --once
npm run --silent status -- --json
npm run status -- --url http://127.0.0.1:8787
```

一次性模式默认给出当前运行最新 50 条请求；JSON 同时包含原始 usage、参数变换和 metadata。更多历史可通过只读 requests 接口游标查询。历史来自 SQLite，旧 JSON 报告不会自动导入。停止网关后监控不能在线查询历史；重新启动网关后可继续查看。
